# 1.0 实机测试清单 / Live-test checklist

当前状态：**1.0 Beta**（`1.0.0-beta.1`）。本文件只列待测项目；编写和离线测试期间不得自动启动游戏。只有用户明确说当前可以占用 Steam 家庭库时，才执行这些测试。

Current status: **1.0 Beta** (`1.0.0-beta.1`). This file records pending live tests. Development and offline tests must never start the game automatically. Run these only after the user explicitly confirms that the shared Steam library is available.

## 0. 前置保护 / Preconditions

- [ ] 确认家庭库当前无人占用，并由用户明确授权本次启动。
- [ ] 记录 `user1.dat`、`users.dat` 的大小、时间与 SHA-256；创建存档保险箱快照。
- [ ] 从 Steam 正常启动 AppID 3590，不直接运行 DRM 包装 EXE。
- [ ] 只读确认进程为 x86、磁盘 SHA-256、运行时 PE timestamp `0x4D02B058`、Lawn/Board/UI/scene 合理。
- [ ] 所有补丁与调用目标先验证原字节/短签名；任何不符立即停止，不尝试替代地址。

## 1. 高级暂停 / Advanced Pause

- [ ] 只读抓取 Steam 1096 的 `Board::Update`，生成全模块唯一 AOB；人工确认跳转仍在同一函数边界内。
- [ ] 冻结僵尸、植物动画、子弹、掉落物、冷却与波计时。
- [ ] 暂停时仍可选卡、种植、铲除、发射玉米加农炮，光标预览和画面刷新正常。
- [ ] F3、按钮、切出/切回、离开关卡与关闭修改器都正确恢复；0/多重 AOB 命中必须零写入。

## 2. 便利功能 / Convenience

- [ ] 速度 `0.25/0.5/0.75/1/1.5/2/3/5/10×` 与 F4 往返，退出恢复原帧时长。
- [ ] 自动收集分别覆盖阳光、银币、金币、钻石、巧克力、礼物；不误点关卡对象。
- [ ] 与另一修改器已启用同一补丁时，本工具提示占用且退出不覆盖对方状态。
- [ ] 总开关、僵尸/植物分开开关；每个对象只有对应血条，关闭后覆盖窗口立即隐藏且不挡鼠标。
- [ ] 僵尸行走、跳跃、潜水、飞行、矿工转向、巨人与僵王时血条持续跟随；植物叠层血条不重叠。
- [ ] 窗口/全屏、100%/125%/150% DPI、最小化、Alt+Tab、关卡切换下位置正确；切到其他程序时不残留。

## 3. 模式 / Modes

- [ ] 一周目前按钮被拒绝；完成一周目后可显示/隐藏 Limbo Page，且不编辑用户档解锁字段。
- [ ] Day/Night/Fog/Roof Endless 分别能进入、选卡、完成至少 20 波并进入下一轮；Pool Endless 保持原入口。
- [ ] Limbo 小游戏逐项记录：可进入、胜负条件、退出、潜在闪退；内部未完成条目仍无一键启动。
- [ ] Night Roof 仅在 Roof Endless 开启，背景/音乐/僵尸路径/墓碑与返回屋顶状态均测试，继续标实验性。

## 4. 挑战规则 / Challenge rules

- [ ] 冒险一周目、重玩、生存和无尽分别测试数量 `1/1.5/2/5/10×`；不超过僵尸槽安全余量。
- [ ] 出怪速度 `0.25/0.5/1/2/5/10×`，包括普通波、旗波、巨大波提示、提前放波和选卡间隔。
- [ ] 本体、头盔、盾牌、飞行血量 current/max 同比例；开关/改倍率不重复乘算。
- [ ] 每波、每旗（10 波）、每次选卡（20 波/2旗）、每关；加法/百分比/乘法、起始值、上限与重置。

## 5. 测试工坊 / Test workshop

- [ ] 僵尸 ID `0–32` 逐一测试；水路、屋顶、舞王边缘、蹦极、雪橇冰道规则均按 UI 护栏。
- [ ] 雪人、白眼、红眼的生成、受伤、死亡和清理。
- [ ] 僵王只在原版最终 Boss 屋顶、无现存 Boss、容量充分时生成；不测试普通场景强放。
- [ ] 独立扶梯仅对存活未压扁的坚果墙/高坚果/南瓜；草地和屋顶；水路拒绝；重复/容量拒绝。
- [ ] “清理本次对象”不清理天然刷出的同类对象，也不清理已复用槽位的新对象；Boss 不走通用清除。

## 6. 存档与恢复 / Saves

- [ ] 备份嵌套/Unicode/空文件，manifest 每个 SHA-256 正确；篡改文件会拒绝恢复。
- [ ] `..`、绝对路径、混合分隔符和越界 manifest 全部拒绝。
- [ ] 游戏运行时禁止恢复；正常恢复先建立 `before-restore` 快照并逐文件校验。
- [ ] 人工模拟复制中断后，说明如何用 pre-restore 快照恢复；确认不会声称事务性完整替换。

## 7. 发布验收 / Release acceptance

- [ ] 中文/英文 UI 全页截图，无截断、乱码、重叠；100%/125%/150% DPI。
- [ ] Windows 10、Windows 11；普通权限；无 .NET 预装机器运行 self-contained 包。
- [ ] Release ZIP 内容、EXE x86/FileVersion、ZIP 与 EXE SHA-256、.NET 许可证文件、源码 tag 一致。
- [ ] 全部关键项通过后才把 `1.0.0-beta.1` 提升为 `1.0.0`。
