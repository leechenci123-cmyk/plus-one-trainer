# +1 修改器 1.0 Beta

[English](README.en.md) · [功能表](docs/FEATURES.md) · [安全模型](docs/SAFETY.md) · [参考与致谢](docs/REFERENCES.md)

一个为经典 PC 单机版 Plants vs. Zombies 制作的方便优先外部工具。主界面只放真正高频的功能；数值作弊、测试对象与高级难度规则分层收纳。

![原创嫩芽机械师](src/PlusOneTrainer/Assets/sprout-mechanic.png)

## 1.0 Beta 重点

- 高级暂停框架：目标是战场停止且仍可选植物、种植、铲除和操作玉米加农炮；Steam 1096 的运行时签名尚待实机验证，因此当前候选版安全禁用按钮、`F3` 与切出暂停，不猜地址。
- 速度与收集：提供 `0.25×–10×` 与自动收集；各档位和全部拾取物列入实机待测。
- 场上血条：可总开关，也可分别显示植物与僵尸；僵尸血条按位置持续跟随。它是外部只读覆盖层，不修改耐久，待实机校准坐标与 DPI。
- 隐藏内容：显示原版 Limbo Page，游玩白天/黑夜/浓雾/屋顶无尽与隐藏小游戏；泳池无尽仍在正常生存页。
- 夜晚屋顶：明确标为场景混合实验；Beta 4 暂时禁用入口，不冒充原版隐藏关。
- 挑战设置：数量、速度、全套耐久与高级增长的界面和计算已完成；为避免未经验证的后台对象写入，候选版暂时禁用应用按钮，列入实机验证后启用。
- 测试工坊：目录包含 0–32 全部僵尸，包括雪人、白眼、红眼与僵王；Beta 4 暂时禁用全部生成与扶梯按钮，等待内部函数实机验证。
- 存档保险箱：不编辑账号，只做整目录快照、逐文件 SHA-256 校验与恢复前备份。
- 中英双语：界面和 README 已双语；技术文档采用同页双语摘要或英文细节。

详细规则见 [1.0 功能表](docs/FEATURES.md)。

## 兼容版本

1.0 只对白名单中的 **Steam GOTY 英文版 1.2.0.1096（32 位）**启用写入：

```text
SHA-256  868F8E2BAB0D6A7EF8AFC4C5960C608ECCEF82BD086BD6E0C0E2670199A5CA45
Steam child runtime PE timestamp  0x4D02B058
```

发现其他版本时，工具会进入只读保护，不会“猜地址”。Beta 4 先验证 Steam 包装父进程的完整磁盘哈希，再连接由该父进程启动的 `popcapgame1.exe` 子进程；子进程还须通过 x86、时间戳、映像基址和运行时游戏对象检查。

## 使用

1. 从 GitHub Releases 下载 `Plus-One-Trainer-1.0.0-beta.4-win-x86.zip` 并解压。
2. 先启动自己合法购买的 Steam PvZ，再运行 `PlusOneTrainer.exe`。
3. 看到绿色“已连接”后使用已验证功能。第一次尝试实验功能前，先在“存档保险箱”创建备份。
4. 正常关闭修改器会恢复仍由本工具拥有的代码补丁；若游戏内部调用超时，窗口会等待调用安全结束再退出。游戏进程关闭后，所有内存修改自然消失。

当前属于 **1.0 Beta 4**（技术版本 `1.0.0-beta.4`）；它增加钱包金钱 `+1000`，并说明自动收集金币在飞入钱包后到账。在 [实机测试清单](docs/LIVE_TEST_CHECKLIST.md) 全部通过前不标为稳定 `1.0.0`。测试工坊、夜晚屋顶、高级暂停和挑战规则写入会保持禁用。

不需要管理员权限。若 Windows 安全软件提示“修改其他进程内存”，请核对下载页哈希与本仓库源码；这是外部修改器工作的必要方式，不应盲目添加全局排除项。

## 安全边界

- 不修改 `PlantsVsZombies.exe`、`main.pak` 或 Steam 文件；不注入 DLL。
- 不绕过 Steam/DRM，不包含游戏本体或官方资源。
- 不支持联网、排行榜、反作弊绕过或成就伪造。
- 远程对象创建框架采用短暂、可审计的 x86 调用片段，但 Beta 4 不开放任何内部调用入口。
- 僵王、普通僵尸和场地扶梯的生成在 Beta 4 全部禁用，等待后续实机验证。

完整说明见 [安全模型](docs/SAFETY.md)。

## 从源码构建

需要 Windows 10/11 与 .NET 8 SDK：

```powershell
./scripts/build.ps1 -Configuration Release
./scripts/test.ps1
./scripts/package.ps1 -Version 1.0.0-beta.4
```

发布包是 `win-x86` 自包含单文件，不要求使用者另装 .NET。
